# Valthera3D

Tienda de figuras personalizadas impresas en 3D.

## Web pública (GitHub Pages)

Cuando Pages esté activo la web quedará en:

https://amarnie30-dotcom.github.io/valthera3d/

### Activar Pages (un minuto)

1. Abre https://github.com/amarnie30-dotcom/valthera3d/settings/pages
2. En **Build and deployment** → **Source** elige **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Save
5. Espera 1–2 minutos y abre el enlace de arriba en el iPhone

### Fotos

Sube la carpeta `img` al repositorio:
Add file → Upload files → arrastra las fotos dentro de `img/`.
